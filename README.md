# ezra-vernon-site

Ezra Vernon's personal site: plain static HTML, no build step.

Pages: `index.html` (Home), `dreams.html`, `sidequests.html`, `quotes.html`, `training.html`, `socials.html`, `404.html`.
Photos live in `images/`, training data in `data/activities.json`. Editing notes are in the comment at the top of `index.html`.

Deployed on Vercel. `vercel.json` turns off the build step and serves the repo root as-is.
