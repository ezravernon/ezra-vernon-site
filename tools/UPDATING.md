# Updating the Training page from COROS

The site in `site/` is plain static HTML. Every page is generated by `tools/build.py`
(which also runs `tools/build_training.py`). Never hand-edit files in `site/`;
change the builder or the data, then rebuild.

## Data file

`tools/coros/activities.tsv` — one activity per line, **newest first**, tab-separated:

| column | example | notes |
|---|---|---|
| date | `2026-11-09` | activity date (COROS profile timezone) |
| coros_sport_code | `100` | COROS numeric sport type (100 run, 102 trail run, 104 hike, 200 ride, 402 strength, 500 ski, 700 rowing, 800 indoor climb, 900 walk, 1003 soccer, 1100 frisbee) |
| duration | `37:22` or `1:20:55` | exactly as COROS reports it |
| distance_or_sets | `7.28 km`, `527 m`, `sets 13`, or `-` | `-` when there is no distance or sets |
| avg_hr_bpm | `178` | average heart rate, integer |
| title | `Royal Victoria Marathon` | optional, see privacy rules |

## Weekly update procedure

1. Read the newest date in `activities.tsv`.
2. Query COROS (`querySportRecords`) from **that date** to today, with a high limit (e.g. 200).
3. For each returned activity not already in the file (same date + sport code + duration = duplicate), add a line.
   Keep the file newest first; for several activities on one day keep COROS's order.
4. Privacy rules — these are not optional:
   - **Never** write start coordinates, place/location names, calories or anything else beyond the six columns.
   - COROS's "Location" field is usually an auto name like `Victoria Run`, `Saanich Walk`, `Capital Regional District Road Bike`,
     `Indoor Climb`, `Strength`, `Trail Run`. Those are NOT titles: leave the title empty.
   - Only keep a title when it is a name Ezra wrote for the workout or an event name (e.g. `Royal Victoria Marathon`,
     `Long run, trails x4`, `Recovery`). For strength workouts drop a `Day N |` prefix and write the body part in sentence case
     (`Day 1 | Chest/Triceps` -> `Chest / triceps`).
   - If unsure whether something is a place name, leave the title empty.
5. Obvious mis-recordings (e.g. a "frisbee" at 20 km/h = a car drive) go in `EXCLUDE` in `build_training.py`, not deleted from the TSV.
6. Rebuild: `python3 tools/build.py` (from the repo root). It writes `site/` and stamps today's date as "Updated".
7. Check: every page in `site/` exists, `site/data/activities.json` parses, its activity count grew by the number of lines added,
   and `git diff --stat` only touches `tools/coros/activities.tsv`, `site/training.html` and `site/data/activities.json`
   (plus `build_training.py` if an exclusion was added, and `site/data/secret.json` from the secret rotation).
   If anything else changed, stop and report instead of pushing.
8. Commit as `Ezra Vernon <ezravernon@users.noreply.github.com>` with a message like
   `Training data: +4 activities (Nov 10–15)` and push.
9. If there were no new activities, leave the Training files alone, but still do the secret-section password rotation
   (`tools/SECRET.md`) and push that.
